# 마이링크(MyLink) 기능 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 인스타그램, 틱톡 등 단일 링크만 허용되는 소셜 미디어 프로필에 여러 개의 링크를 통합하여 보여줄 수 있는 멀티 링크 페이지 제공 서비스 (Linktree 클론)
- **대상 사용자**: 
  - 여러 소셜 미디어 채널이나 포트폴리오, 쇼핑몰 등을 하나로 묶어서 홍보하고 싶은 크리에이터, 인플루언서
  - 개인 포트폴리오 링크들을 깔끔하게 정리하고 싶은 프리랜서 및 취업 준비생
  - 자사 제품 및 이벤트 링크를 한곳에서 관리하려는 소상공인 및 기업 마케터

## 2. 핵심 기능 목록

### 필수 기능 (Must-Have)
1. **회원 인증 및 관리** (로그인, 회원가입)
2. **프로필 관리** (프로필 이미지, 이름, 짧은 소개글)
3. **링크 관리** (링크 추가, 수정, 삭제, 순서 변경)
4. **마이링크 페이지 제공** (고유 URL 제공, 방문자용 조회 페이지)

### 선택/확장 기능 (Nice-to-Have)
1. **테마 및 디자인 커스터마이징** (배경색, 버튼 스타일, 폰트 변경 등)
2. **방문자 통계(Analytics)** (총 조회수, 링크별 클릭수 추적)
3. **소셜 아이콘 링크** (하단 고정 소셜 미디어 전용 아이콘 배치)
4. **QR 코드 생성** (오프라인 홍보용 고유 URL QR코드 제공)

---

## 3. 기능 상세 설명

### [필수] 회원 인증 및 관리
- **회원가입**: 이메일 주소 및 비밀번호, 또는 소셜 계정(Google, GitHub 등)을 이용해 가입할 수 있다.
- **고유 아이디(URL) 설정**: 회원가입 시 자신만의 고유한 마이링크 주소(`mylink.com/@username`)를 설정할 수 있다. (중복 방지 로직 필요)
- **로그인/로그아웃**: 생성한 계정으로 로그인하여 대시보드(관리자 페이지)에 접근할 수 있다.

### [필수] 프로필 관리
- **프로필 이미지 업로드**: 방문자에게 보여질 대표 이미지를 업로드하고 수정할 수 있다.
- **사용자 이름 및 소개글**: 본인의 이름(닉네임)과 자신을 소개하는 짧은 텍스트(Bio)를 작성할 수 있다.

### [필수] 링크 관리
- **링크 추가**: 제목(Title)과 URL을 입력하여 새로운 링크 버튼을 생성할 수 있다.
- **링크 수정/삭제**: 기존에 작성된 링크의 제목이나 URL을 수정하거나 불필요한 링크를 삭제할 수 있다.
- **순서 변경(Drag & Drop)**: 사용자가 원하는 순서대로 링크의 배치 순서를 드래그 앤 드롭으로 자유롭게 변경할 수 있다.
- **링크 활성/비활성(토글)**: 삭제하지 않고 임시로 방문자에게 보이지 않도록 숨김 처리할 수 있다.

### [필수] 마이링크 페이지 제공
- **퍼블릭 페이지**: 로그인하지 않은 일반 방문자가 `mylink.com/@username`으로 접속했을 때 프로필과 링크 버튼들이 렌더링되어 보여지는 랜딩 페이지.
- **반응형 디자인**: 모바일 세로 화면에 최적화되면서도 데스크탑/태블릿에서도 어색하지 않게 보이는 UI 제공.

### [선택] 테마 및 디자인 커스터마이징
- **프리셋 테마**: 제공되는 몇 가지 기본 테마(다크, 라이트, 네오브루탈리즘 등) 중에서 선택할 수 있다.
- **버튼 및 배경 스타일링**: 버튼의 모양(둥근 모서리, 각진 모서리)과 배경색을 직접 지정할 수 있다.

### [선택] 방문자 통계 (Analytics)
- **대시보드 통계 요약**: 관리자 페이지에서 내 페이지의 '총 방문자 수(Views)'와 '총 클릭 수(Clicks)'를 확인할 수 있다.
- **개별 링크 클릭 통계**: 어떤 링크가 가장 많이 클릭되었는지 개별 수치를 제공하여 마케팅 성과를 분석할 수 있다.

### [선택] 소셜 아이콘 링크
- 일반 텍스트 버튼 외에, 하단이나 상단에 작게 배치되는 소셜 미디어(Instagram, Twitter, YouTube 등) 전용 아이콘 링크를 별도로 설정할 수 있다.

### [선택] QR 코드 생성
- 사용자의 고유 마이링크 URL로 연결되는 QR 코드를 이미지 형태로 다운로드할 수 있도록 제공한다.

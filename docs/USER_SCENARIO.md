# 마이링크(MyLink) 사용자 시나리오

## 1. 방문자: 마이링크 페이지 방문 과정

- 사용자는 **소유자의 다양한 활동을 한눈에 확인하기 위해** 소유자의 고유 URL(`mylink.com/@username`)에 접속한다.
- 사용자는 **소유자가 어떤 사람인지 알아보기 위해** 상단에 렌더링된 프로필 이미지, 닉네임, 그리고 소개글을 확인한다.
- 사용자는 **관심 있는 소유자의 특정 작업물이나 사이트를 보기 위해** 화면에 나열된 여러 링크 버튼의 제목과 파비콘(Favicon) 아이콘을 탐색한다.
- 사용자는 **소유자의 깃허브나 SNS 플랫폼으로 넘어가기 위해** 하단에 고정된 소셜 전용 아이콘을 클릭한다.
- 사용자는 **원하는 특정 목적지(포트폴리오, 블로그 등)로 이동하기 위해** 가장 눈에 띄거나 목적에 맞는 링크 버튼을 클릭한다.

---

## 2. 소유자: 링크 추가/수정/삭제 과정

### 2.1. 링크 추가 과정
- 사용자는 **본인의 마이링크 관리자 대시보드에 접근하기 위해** 구글 소셜 로그인(Firebase)을 통해 로그인한다.
- 사용자는 **새로운 작업물이나 블로그 주소를 방문자에게 공유하기 위해** '새 링크 추가' 버튼을 클릭한다.
- 사용자는 **방문자에게 링크의 목적을 명확히 전달하기 위해** 링크 제목(Title)과 대상 URL을 입력 폼에 작성한다.
- 사용자는 **입력한 링크를 방문자 페이지에 공개하기 위해** '저장(추가)' 버튼을 누른다.
- 사용자는 **아이콘이 정상적으로 표시되는지 확인하기 위해** 자동으로 추출되어 적용된 해당 URL의 파비콘(Favicon)을 화면에서 확인한다.

### 2.2. 링크 수정 과정
- 사용자는 **기존에 등록한 링크의 URL 주소가 변경되었거나 제목을 다듬기 위해** 대시보드의 링크 목록에서 해당 링크의 '수정' 버튼(아이콘)을 클릭한다.
- 사용자는 **올바른 정보로 갱신하기 위해** 입력 폼에 활성화된 기존 제목이나 URL을 새로운 내용으로 변경한다.
- 사용자는 **변경된 내용을 퍼블릭 페이지에 반영하기 위해** '수정 완료' 버튼을 클릭한다.

### 2.3. 링크 삭제 과정
- 사용자는 **더 이상 유효하지 않거나 노출하고 싶지 않은 링크를 없애기 위해** 대시보드의 링크 목록에서 해당 링크의 '삭제' 버튼(아이콘)을 클릭한다.
- 사용자는 **실수로 삭제하는 상황을 방지하기 위해** 화면에 나타난 삭제 재확인 모달(팝업) 창에서 '확인'을 클릭한다.
- 사용자는 **해당 링크가 방문자에게 더 이상 보이지 않음을 점검하기 위해** 목록에서 해당 링크가 완전히 사라진 것을 확인한다.

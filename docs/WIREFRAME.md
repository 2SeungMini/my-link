# 마이링크(MyLink) 와이어프레임 및 화면 흐름도

이 문서는 마이링크 서비스의 화면 흐름(Flow)과 핵심 화면의 ASCII 기반 와이어프레임을 정의합니다.

## 1. 화면 흐름도 (Screen Flow)
Mermaid를 활용하여 방문자와 소유자의 화면 이동 흐름을 나타냅니다.

```mermaid
graph TD
    %% 소유자 흐름
    Owner([소유자 접속]) --> Login{구글 소셜 로그인}
    Login -->|성공| Dashboard[관리자 대시보드]
    Dashboard --> EditProfile[프로필 수정]
    Dashboard --> ManageLinks[링크 관리]
    ManageLinks --> AddLink[새 링크 추가]
    ManageLinks --> EditDelLink[링크 수정/삭제]
    Dashboard --> Preview[내 페이지 미리보기]

    %% 방문자 흐름
    Visitor([방문자 접속]) --> PublicURL[mylink.com/@username]
    PublicURL --> LandingPage{퍼블릭 랜딩 페이지}
    LandingPage -->|버튼 클릭| TargetURL[대상 웹사이트 이동]
    LandingPage -->|소셜 아이콘 클릭| SocialMedia[소셜 미디어 이동]
```

---

## 2. ASCII 아트 와이어프레임 (Wireframes)

shadcn/ui 기반의 모던하고 직관적인 디자인 시스템을 적용하기 전, 핵심 요소들의 배치를 보여주는 와이어프레임입니다.

### 2.1. 퍼블릭 랜딩 페이지 (방문자 뷰)
모바일에 최적화된 세로형 UI로, 프로필과 링크 버튼들이 수직으로 정렬됩니다.

```text
+-------------------------------------------------+
|                                                 |
|                                       [공유]    |
|                                                 |
|              ( 프로필 이미지 )                  |
|                                                 |
|               @username                         |
|      Frontend Developer & Creator               |
|                                                 |
| =============================================== |
|                                                 |
|  +-------------------------------------------+  |
|  | [Favicon]  My Tech Blog                   |  |
|  +-------------------------------------------+  |
|                                                 |
|  +-------------------------------------------+  |
|  | [Favicon]  GitHub Portfolio               |  |
|  +-------------------------------------------+  |
|                                                 |
|  +-------------------------------------------+  |
|  | [Favicon]  YouTube Channel                |  |
|  +-------------------------------------------+  |
|                                                 |
|                                                 |
|         [IG]   [TW]   [GH]   [YT]               |
|                                                 |
|             Powered by MyLink                   |
|                                                 |
+-------------------------------------------------+
```

### 2.2. 관리자 대시보드 (소유자 뷰)
링크 추가, 수정, 삭제를 직관적으로 할 수 있는 대시보드 뷰입니다. (데스크탑/모바일 반응형)

```text
+-------------------------------------------------+
|  ✨ MyLink Admin                    [ 로그아웃 ]|
+-------------------------------------------------+
|                                                 |
|  [ 내 페이지 주소: mylink.com/@username ] [복사]|
|                                                 |
|  [ 프로필 설정 ] -------------------------------+  
|  |                                           |  |
|  |  ( Image ) 이름: [ Caesium Y            ] |  |
|  |            소개: [ Frontend Developer   ] |  |
|  |                                  [ 저장 ] |  |
|  +-------------------------------------------+  |
|                                                 |
|  [ + 새 링크 추가하기 ]                         |
|                                                 |
|  [ 내 링크 목록 ] ------------------------------+
|  |                                           |  |
|  | +---------------------------------------+ |  |
|  | | 제목: [ My Tech Blog                ] | |  |
|  | | URL:  [ https://blog.example.com    ] | |  |
|  | | [파비콘]             [ 수정 ] [ 삭제 ]| |  |
|  | +---------------------------------------+ |  |
|  |                                           |  |
|  | +---------------------------------------+ |  |
|  | | 제목: [ GitHub Portfolio            ] | |  |
|  | | URL:  [ https://github.com/example  ] | |  |
|  | | [파비콘]             [ 수정 ] [ 삭제 ]| |  |
|  | +---------------------------------------+ |  |
|  +-------------------------------------------+  |
|                                                 |
+-------------------------------------------------+
```
